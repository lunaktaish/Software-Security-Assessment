## Security Testing & Evaluation

A controlled dataset of 30 synthetic user accounts was created using `GROUP_SEED = 25493314` and divided into three password-strength levels: weak (`user_db1–user_db10`), medium (`user_db11–user_db20`), and strong (`user_db21–user_db30`). The groups differ in password length, complexity, predictability, and character variety, allowing us to evaluate how password strength affects resistance to different attacks. Using this dataset, we conducted controlled Brute Force and Password Spraying simulations in a local testing environment and measured both attack success rates and execution times. The experiments also evaluated the effectiveness of different password-hashing approaches and security mechanisms, including SHA-256, bcrypt, Argon2id, Rate Limiting, Account Lockout, TOTP, Pepper, and CAPTCHA. The collected results were analyzed to compare the security effectiveness and performance impact of each configuration and combination of defenses. A detailed description of the methodology, measurements, results, and analysis is available in the project report.
